# Fase de Aplicação

Esta fase reúne o trabalho de verificação da qualidade do produto: a execução
das questões e métricas definidas no [roteiro da análise](../analise/roteiro.md)
sobre o Excalidraw, com o registro das evidências e dos resultados de cada
característica.

## Versão analisada

Para que os resultados sejam reproduzíveis, a análise foi fixada no commit
[`e7b5346`](https://github.com/excalidraw/excalidraw/commit/e7b534668a60add7f725531f3c9abf32508c7b4e)
do repositório do Excalidraw. Toda inspeção de código-fonte, dependências e
configurações refere-se a essa versão, mesmo que o projeto receba novas
alterações durante o trabalho.

!!! note "Escopo do commit"
    O commit delimita a análise do código-fonte. Os testes feitos na versão web
    pública podem refletir uma versão posterior; quando isso ocorrer, será
    registrado na página da característica correspondente.
