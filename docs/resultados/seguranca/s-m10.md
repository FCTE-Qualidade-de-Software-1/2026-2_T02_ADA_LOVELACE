# S-M10 · Passar-se por outro participante

**Nota 0**: sim, dá para se passar por outro participante. Numa sala com
Alice, Bruno e Carlos, Carlos trocou o nome para "Alice" e passou a aparecer
assim para os outros dois. Não houve alerta, bloqueio nem rejeição do servidor
(1 de 1 tentativa aceita).

| Janela | Nomes exibidos depois da troca |
| --- | --- |
| Alice | Alice (You), Alice, Bruno |
| Bruno | Bruno (You), Alice, Alice |
| Carlos | Alice (You), Alice, Bruno |

O servidor atribui o `socketId`, mas o `username` vem do cliente e não fica
ligado a ele. Também não há verificação de nome repetido.

!!! note "Limites da coleta"
    As três janelas eram abas do mesmo perfil do navegador, cada uma com sua
    conexão. O nome foi trocado por `window.collab.setUsername`, o mesmo
    método que o campo "Your name" chama.
