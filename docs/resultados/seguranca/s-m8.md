# S-M8 · Histórico de versões com autoria

**Nota 0**: a versão gratuita não tem histórico de versões. A interface só
oferece **Desfazer** e **Refazer**. Não há lista de versões, restauração,
comparação, data nem autor de cada alteração.

Desfazer e refazer não contam: são uma pilha de edição local do cliente e não
guardam versões com autor. Reabrir a sala mostra a cena atual, não versões
anteriores.

!!! note "Excalidraw+ não comparado"
    A coleta não verificou o Excalidraw+. Por isso não havia base para a nota
    1 ("só no Excalidraw+"), e o resultado vale para a versão gratuita.
